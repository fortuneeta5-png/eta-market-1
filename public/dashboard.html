Documentation API EtaChop

Version 1 · Base URL et premiers endpoints disponibles

v1
BASE URL

Authentification

Ajoute ta clé API dans l’en-tête Authorization de chaque requête.

Authorization: Bearer ETA_VOTRE_CLE_API
apikey: CLE_PUBLIQUE_ETACHOP
Content-Type: application/json

Endpoints disponibles

GET/storeInformations de ta boutique
GET/productsListe des produits actifs (100 max.)
GET/ordersCommandes de ta boutique (100 max.)

Exemple JavaScript

const response = await fetch("API_BASE_URL/products", {
  headers: { Authorization: "Bearer ETA_VOTRE_CLE_API", apikey: "CLE_PUBLIQUE_ETACHOP" }
});
const result = await response.json();

Les commandes et les produits retournés sont limités à la boutique liée à la clé. Les opérations d’écriture et les paiements API ne sont pas encore ouverts dans cette version.

Environnement Sandbox

Un espace de test isolé pour valider tes intégrations.

TEST
Mode test activé

Crée une clé « Sandbox » depuis l’onglet Clés API. Elle porte le préfixe eta_test_. Les réponses Sandbox utilisent des exemples fictifs. Elles ne lisent ni ne modifient tes commandes réelles et ne déclenchent aucun paiement.
